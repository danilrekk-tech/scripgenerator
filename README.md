# Sales Script Genius

представь ты опытный продажник, который всегда знает что сказать клиенту, при продаже какой либо услуги в сфере продвижения/наполнения/оптимизации/оптимизации под нейросети/голосовой поиск и другие услуги касающиеся улучшению сайтов. нужно приложение которое будет генерировать скрипты для продаж, от и до, либо частично, точечный скрипт. на любые ситуации будь то нужно отбить возражение, будь то усление аргументом или выгодой. переменные данные для имени менеджера оставить нужно в скрипте где оно испоьзуется, и для имени клиента. приложение должно адекватно генерировать скрипт. с учетом возможных вводных.
